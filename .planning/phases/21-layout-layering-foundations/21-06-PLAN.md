<objective>
Draw the show date on both share-card footers as "Mon D, YYYY", and constrain the footer line to
the card margins by ellipsizing the venue — never the date.

Purpose: FOUND-05. The footer `date · venue` line is drawn by `centerText` at a fixed 44px with
**no width constraint** (`shareCard.ts:194` and `:424`) on a 1080×1350 canvas. "Mon D, YYYY" is
~2 characters longer than the ISO string it replaces, so this change makes an existing overflow
risk worse. D-36 fixes it with code that already ships: `truncateToWidth` (`shareCard.ts:252`)
and the `width * 0.9` margin the badge row already uses at `:417`. No new drawing code is needed.

Output: a module-private `composeFooterLine` used by both footer draws, and unit coverage
proving the date survives while the venue ellipsizes.
</objective>
