<objective>
Ship NAV-01/02/03 as one change: move the five bottom-tab labels into `config.copy` under their
new short names, add the separate presence label voice off the same frozen wire tokens, and give
an unresolvable activity a constant readable fallback.

Purpose: NAV-01 shortens the tab strip so five tabs fit under a thumb. That falsifies the
shipped comment at `presenceActivity.ts:20-23` ("These ARE the display labels … so no separate
label map is needed") — a friend's dot must never read "Alex is on Me" (D-40). The wire
vocabulary stays frozen, which is precisely the mechanism that makes NAV-03's two-direction test
pass: resolution is receiver-side, so old builds are immutable and only a frozen vocabulary makes
both directions correct.

Output: two label maps in `config.copy`, a `BottomTabBar` that reads them, a
`PresenceActivitySlot` that resolves through the presence map with a constant fallback, and
tests locking both the rename discipline and the fallback.
</objective>

The label is always a **constant string chosen by a map** — `config.copy.presence.activity[tab] ?? config.copy.presence.activityUnknown`, never `?? activity.tab`.
