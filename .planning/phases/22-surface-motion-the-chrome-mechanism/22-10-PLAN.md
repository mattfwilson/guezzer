<objective>
Convert the phase's two **bottom-sheet** exit exemplars — `TrailNodeSheet` and `WhyDetail` — from
unmount-driven to prop-driven, and correct `Sheet.tsx`'s seam list so it names only the sites that
genuinely remain unmount-driven.

Purpose: **owner decision, 2026-08-06**, escalated per `22-RESEARCH.md` §Open Question 1. `<Sheet>` can
only exit-animate a surface whose **`open` prop** flips; a sheet whose *parent* stops rendering it dies
synchronously, `AnimatePresence` and all. Without a bottom-sheet conversion, four bottom-sheet openings
would ship enter-only against ROADMAP criterion 1's requirement that every bottom sheet animate down on
close — and a module comment is documentation, not delivery.

Both of these are the trivial `return null`-early shape `22-RESEARCH.md` §Pitfall 1 identifies, both are
always mounted by `ShowView`, and each edit stays individually revertible (D-17).

**This plan runs AFTER 22-04, in wave 4, and that ordering is load-bearing.** The conversion inventory

**Still a documented seam, deliberately not converted:** `PinSheet` ×2 (the `initialFocusRef` twin whose

## Planner decision — the exiting frame needs a payload

Both components read their payload (`entry`, `candidate`) for the sheet's `ariaLabel` **and** its body.
Once the sheet is prop-driven, the frame in which `open` flips false is a frame in which the payload is
already `null`, and `AnimatePresence` will keep rendering that element for ~200ms.

**Hold the last non-null payload in a `useRef`** and render from the ref while exiting. `22-RESEARCH.md`
§Pitfall 1 option (B) names this exact technique. Two rules:
  - Update the ref on every render where the prop is non-null, then render from
    `payload ?? lastPayloadRef.current`. Never write to a ref inside an effect for this — the exiting
    render must already have the value.
  - If both are null (first mount, before anything was ever opened), render `<Sheet open={false}>` with
    an empty body and a safe fallback `ariaLabel`. `<Sheet open={false}>` produces **zero DOM nodes**
    (plan 22-01's `AnimatePresence`-with-no-child path), so an always-mounted closed sheet costs nothing.

**Do not move any state out of these components.** `TrailNodeSheet` keeps its `searchOpen` /
`confirmingDelete` `useState` and its `close()` reset; `WhyDetail` stays stateless. The conversion is a
render-shape change, not a state refactor.
