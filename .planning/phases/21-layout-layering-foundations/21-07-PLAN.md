<objective>
Establish the single owner for the app's bottom-space arithmetic — numbers in `config.ts`, one
composition module writing CSS custom properties to `document.documentElement`, the raw
`env(safe-area-inset-bottom)` declared once in `styles.css :root` — and convert the first
surface group (tab bar + `<main>`). Remove the body-level bottom inset if, and only if, plan
21-04's measurement licensed it.

Purpose: FOUND-02's own wording is "a search for the tab-bar height returns exactly one owner".
Today the arithmetic exists in four notations across nine files that disagree by one safe-area
inset, and three v2.1 features consume it. D-13 makes this first commit behavior-preserving for
everything except the one evidence-gated `styles.css` line. D-16 requires the chrome-collapse
seam to exist now, pinned, so Phase 22 flips one source instead of revisiting every call site in
a second layout state.

Output: `config.ui.bottomSpace`, `packages/app/src/layout/bottomSpace.ts`, the `:root`
declaration, converted `AppShell` and `BottomTabBar`, and `packages/app/test/bottomSpace.test.ts`.
The D-12 source guard lands in plan 21-10, once every surface is converted.
